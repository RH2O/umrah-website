# موقع مكتب العمرة

موقع ثابت (HTML/CSS/JS) باللغة العربية، لا يحتاج إلى أي خادم أو أدوات بناء.
افتح `index.html` في المتصفح مباشرة، أو ارفع المجلد كاملاً إلى أي استضافة ثابتة
(GitHub Pages، Netlify، Cloudflare Pages، أو استضافتك الحالية).

## الملفات

```
index.html      الصفحة الرئيسية (كل الأقسام)
css/style.css   التنسيق والألوان
js/main.js      قائمة الجوال وعارض الصور
images/         الصور
```

## بيانات يجب استبدالها في index.html

| ما الذي تستبدله | القيمة الحالية (مثال) |
|---|---|
| اسم المكتب | مكتب السلام للحج والعمرة |
| العنوان | الرياض – حي العليا، طريق الملك فهد |
| رقم الهاتف | ‎+966 50 000 0000 (في `tel:` و`wa.me/`) |
| البريد الإلكتروني | info@example.com |
| ساعات العمل | السبت – الخميس … |
| الخريطة | رابط `iframe` في قسم «موقعنا» ورابط «افتح في خرائط جوجل» |

### تحديث الخريطة

1. افتح موقع مكتبك في خرائط جوجل.
2. اضغط «مشاركة» ثم «تضمين خريطة» وانسخ قيمة `src`.
3. ضعها مكان قيمة `src` في وسم `iframe` داخل قسم `#location`.

## الصور

الصور من Wikimedia Commons بتراخيص حرّة (CC BY / CC BY-SA / CC0).
أسماء المصورين وروابط التراخيص موجودة في التذييل تحت «حقوق الصور»، فلا تحذفها
ما دمت تستخدم هذه الصور. لاستبدالها بصور مكتبك ضع الصور الجديدة في `images/` بنفس الأسماء.
